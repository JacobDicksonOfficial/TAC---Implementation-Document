\section{Overview of the project}

This project documents the design and development of TAC Industries and it's secure infrastructure and case management platform. The purpose of this chapter is to introduce the overall context of the project, to outline the motivation behind the system, and to clearly define the scope and objectives for the Phase One of development of the semester.

The project is motivated by the growing requirement for secure, audit-able, and role-based information systems within investigative and intelligence-driven environments.


\section{Motivation and Problem Statement}

Investigative and intelligence-driven systems routinely handle sensitive personal data, operational intelligence, and evidential records. In many existing environments, security controls are applied inconsistently, with implicit trust often placed in network location, administrator roles, or endpoint devices. Such assumptions significantly increase exposure to insider threats, credential compromise, lateral movement, and unauthorized access to sensitive information.

The motivation for this project arises from the need to design a system in which trust is derived from verified identity rather than physical or logical network placement. Administrative access must be tightly controlled, broken down, and fully auditable, while sensitive data must be protected through role and context-aware policy enforcement. Crucially, security controls should be embedded into the core architecture of the system rather than introduced as an afterthought.

This project addresses the challenge of designing a secure, realistic and governable investigative platform that demonstrates how Zero Trust principles, least-privilege access, and strong identity management can be applied cohesively within a case management environment.


\section{Project Objectives}

In addition, the project aims to define a privileged access model that removes direct administrative access to systems and replaces it with controlled, audited, and brokered access pathways using a Zero Trust Model. A further objective is to design a secure and ethical application data model suitable for investigative case and person records, incorporating audit-ability, life-cycle controls, and responsible handling of sensitive information.

Semester One focuses exclusively on research, architectural design, and validation activities. The scope of this phase includes high-level network and infrastructure design, identity and access management architecture, secure access pathways for both users and administrators, conceptual application data modelling, and the validation of key design assumptions through limited prototyping.

To maintain a controlled and achievable scope, several elements are explicitly deferred to Semester Two. These include full application feature implementation, complete enforcement of access control rules at the API level, advanced automation and system hardening, production-grade monitoring and alerting, and high-availability or disaster recovery design.
